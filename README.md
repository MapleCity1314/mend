mend applies the edits AI models write — unified diffs, SEARCH/REPLACE blocks, V4A patches and JSON edits — to a tree of text files, finding each edit's lines at the first of three matching tiers and writing every change or none.

## Run it

```sh
node main.ts [options] [PATCH]
```
